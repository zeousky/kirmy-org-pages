Questions

General

What is Core?

Core is one place for a Discord bot, an AI API, and VPS hosting.

What services does Core offer?

Core Bot, the Core AI API, and Core VPS. Each one has its own features, price, and who can use it.

Do I need a Discord account to use Core?

Yes, if you want to configure a bot or open the API dashboard. The public pages don’t need an account.

Does Core work on mobile?

Yes. The site works on phones, tablets, and computers.

Are all Core services included in one subscription?

No. VPS, the API, and Core Bot are separate. Premium is listed on its own page too.

AI API and models

Which models does the API offer?

core-1.3-nova and core-1.1-mini.

Which models are in the wider Core lineup?

core-1.1-big, core-1.2-nova, core-1.3-nova and core-1.1-mini.

Can I access every model through the API?

Not currently. Only core-1.3-nova and core-1.1-mini are offered through the API.

Is the Core AI API free?

Yes. The free plan works, with a smaller monthly allowance.

What does the paid API plan include?

More requests each month than the free plan. You can buy it with Robux on Core, or open a support ticket to pay in USD.

Is paid API usage unlimited?

No. You get more requests each month. It is not unlimited.

Does Premium include unlimited API requests?

No. Premium’s unlimited AI is only on the Core website, where that feature is available. The API has its own limits.

How do I integrate the API?

Use the endpoint, auth, and docs Core gives you. They aren’t written out on this page yet.

Will more models be added?

Maybe. The list can change. Nothing here promises a model or a date.

Core Bot and Premium

What is Core Bot?

It lets you set up Discord bot features from a simple page, instead of building the bot yourself.

How many servers can I configure for free?

Up to 2 Discord servers.

What does the paid Core Bot plan include?

Three more servers, so 5 in total, plus the Premium benefits. Buy with Robux on Core, or open a ticket to pay in USD.

What is Core Premium?

More room and higher limits for custom code on the Discord server you choose, plus the advanced features.

Does Premium include unlimited AI usage?

Only on the Core website, and only where that feature is available. It does not make the API unlimited.

How much does Premium cost?

$5 USD or 500 Robux.

How do I upgrade with Robux?

Open Robux checkout on Core, confirm your Roblox account with Dock, then submit the claim after you pay. Staff check it and add the role to your account.

Do I buy Premium separately for each server?

No. One Premium upgrade covers 5 servers instead of 2. This page doesn’t list any extra per-server charge.

VPS hosting

How can I buy a VPS?

For USD, open a support ticket. For Robux, checkout checks your Roblox account with Dock. After a paid order, support sets the server up.

How much does a VPS cost?

Free is $0. Nano is $1.99/month or R$500/month, Micro is $3.99/month or R$750/month, Small is $6.99/month or R$1,000/month, and Medium is $12.99/month or R$1,250/month.

Which plan should I choose?

Pick the size that fits what you want to run. A small bot needs less than a busy app.

What are the specifications?

Free: 1 GB RAM, 1 core, 5 GB. Nano: 2 GB, 1 core, 25 GB. Micro: 4 GB, 2 cores, 50 GB. Small: 8 GB, 2 cores, 100 GB. Medium: 16 GB, 4 cores, 250 GB.

Can I upgrade my VPS later?

Ask support. This page doesn’t explain upgrades.

What can I host?

Bots, apps, and dev projects that fit the server. Whether something runs depends on the app and how the server is set up.

How quickly is a VPS activated?

Ask support. We don’t promise a setup time on this page.

Which operating systems and locations are available?

We haven’t published those yet. When they’re confirmed, they’ll be listed here.

Is a VPS included with Premium?

No. You pay for a VPS on its own.

Payments and accounts

What payment options exist for Premium?

USD goes through a support ticket. Robux opens a Roblox game pass, then you submit a claim for staff to check.

How does the Robux process work?

Choose “for myself” or “gifting”, confirm the Roblox account with Dock, finish checkout, then tell us you’ve paid. We don’t check the payment or grant the role automatically.

Can I use Core on different devices?

Yes. The site works on different screen sizes. We don’t describe extra account-sync features until they exist.

Where can I get support?

In the Core Discord. Use the Support link on this site to open a ticket.

What if a feature is not working?

Read the page for that product first, then message support if it’s still broken.
